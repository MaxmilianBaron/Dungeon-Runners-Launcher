Shared graphical launcher: install, **Play**, signed updates, repair and [Addons](https://github.com/MaxmilianBaron/Dungeon-Runners-Addons). Original artwork cycles every five seconds. **Update turns green** when client or addon updates are available.

Extract the complete ZIP. `Windows`: `Install.cmd` · `Mac`: `Install.command` or the `.app` · `Linux`: `sh Install.sh`. Choose the game folder; existing installations show Play. Close the game before updating. Settings and addon history are preserved.

The launcher runs natively on Windows x64, macOS and Linux x64/arm64; .NET is bundled. The original Windows x86 **game requires compatible Wine/CrossOver on Mac/Linux**. [Platform requirements and build](BUILDING.md).
