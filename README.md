`Install` · `Update` · `Repair` · `Play`. Verified downloads, signed manifests and preserved settings.

Desktop [Addons](https://github.com/MaxmilianBaron/Dungeon-Runners-Addons): `Install` / `Uninstall`; settings in `ESC → Addons`.

Launch additional clients with `Play`. The launcher reopens after its updates.

Launcher links: `Website` · `Armory` · `Leaderboard` · `Discord` · `Desync Report`.

`Windows`: modern UI or native UI for `XP`, `Vista`, `7`, `8`, `8.1`; both support addons.

`macOS`: `Intel` / `Apple Silicon`, `Wine`.

`Linux`: `x64` / `ARM64`, `Wine`; no `FUSE` required.

`Steam Deck`: `Desktop Mode`, `Proton`; use the `Steam Input Gamepad` template.

`Android 9+`: universal `APK`, touch controls; desktop addons are unsupported.
